## 4. 协作方式

- 接口约定：Swagger + 共享 Postman/Apifox 集合  
- 版本管理：Git 分支（main / dev / feature-*）  
- 联调节点：后端 API 冻结后前端/APP 并行  
- 代码评审：核心 PR 需至少 1 人 Review
