# 三、关键技术落地：前后端开发

---

## 用户端

**技术选型：** `uni-app + Vue 3`

**完成的操作：**
`页面展示、用户输入接收、数据校验、接口请求转发;`

**实现的功能：**
`实现登录页、注册页、贷款申请页、个人信息页等10+个核心页面,完成前后端接口联调`

---

## 管理员端

**技术选型：** `HTML5 + CSS3 + JavaScript + Axios`

**完成的操作：**
`页面展示、数据表格渲染、筛选搜索、图表可视化(Canvas API);`

**实现的功能：**
`实现8个管理页面(登录、控制台、申请管理、用户管理、产品管理、报表、设置等),完成前后端接口联调`

---

## 后端

**技术选型：** `Spring Boot 3.2.5 + Spring MVC + Spring Data JPA + Spring @Service + @Transactional`

**完成的操作：**
`HTTP请求接收、参数验证(@Valid)、响应处理、业务规则验证(信用分验证、额度计算)、事务控制、数据库CRUD操作、SQL执行、数据封装;`

**实现的功能：**
`实现7个Controller类(30+个RESTful API接口)、6个核心Service类、5个Repository接口,覆盖申请、审核、放款全流程逻辑,对接MySQL数据库,支持事务回滚`
